Shared design specification
- Near-black page #090909, surfaces #111111, detail dialogs #101010.
- Primary text #fafafa; muted gray supporting text; thin neutral borders.
- Red #ff535b for urgent/critical, yellow #ffcd38 for uncertainty/pending,
  green #45e176 for recorded/authorized outcomes. Every status also has text.
- Local Geist and Geist Mono. Desktop page title 40px, Overview 44px;
  phone 30px. Section titles 24px; body 16px; description 18px desktop.
- Reuse PageHeading, Disclosure and the shared Button/Badge/Dialog/Input
  primitives. Keep the same incident selector, navigation and account controls.
- Main views answer the immediate question first. Put full provenance, audit
  history and editing in explicitly named details; never remove functionality
  or substitute static fixture values just to resemble the image.
- Flat lists, generous spacing, restrained filled selection/urgency states.
  Avoid nested dashboard cards and extra summary grids on main pages.
- Keep existing permission checks. Access paths and group membership are not
  proof of individual compromise. Acknowledgment is not task verification.

Restored page compositions and retained functionality

Overview
Incident title/severity/Add finding; four live summary metrics; three attention
rows; affected business operations table; three recent activities. No containment
banner or decision modal. View all work exposes remaining findings and live task
attention. Incident details and actions exposes metadata, Update incident,
Document update, Attach evidence, New incident, Create task and full scope counts.
Finding selection still opens the complete investigation and source history.

Scope
Focused relationship graph, slim inspector and record browser. Graph tools holds
inventory counts, entity search, graph expansion and asset/relationship editors.
Inspector shows the primary assessment, concise context, other impacts and
evidence disclosures, Assign investigation and Open full investigation.
The full investigation retains every assessment editor, evidence link, asset
editor, relationship action, finding conversion and provenance field.

Operations
Approved request list/detail composition, independent approvers and collapsed
fallback rationale. Preview approval/recovery actions stay disabled and explain
their limitation in tooltips. No fabricated approval execution was added.

Team
Unboxed conversation directory, incident group chat, selected direct message,
participant avatars, flat message stream and simple composer. Actual authorized
group membership, private DMs, references, availability, unread state and source
conversion remain connected. Each message's actions menu exposes Create task
and Add finding. The header's Incident tasks control opens the full task desk;
task links/deep links retain paging, verification and original-source navigation.

Timeline
Colored vertical event feed and slim selected-event pane: what happened,
observed/recorded times, next step, owner and primary evidence/workflow links.
Sources & audit details holds complete descriptions, all references, prior/new
values and correction controls. Filters and Since my last visit use live events
and per-user read cutoffs. The default event is newest; explicit event links
select their actual target. No hardcoded Today label on historical events.

New detail views
Finding/task editors, evidence previews/uploads, investigation, record browser,
task desk, task detail, members and invitations share the typography, restrained
surfaces, borders and action styles. Dialogs scroll within the viewport; tables
scroll within their container on phones. Team controls wrap rather than squeeze
the conversation title. Overview's secondary control moves below rows on phones.

Deliberate differences from static mocks
All live titles, counts, assignees, timestamps, assessments and event content
reflect the database. In particular the graph keeps the real Dataset entity
between database and record group, plus actual edge direction and uncertainty.
Business statuses reflect actual availability assessments; no green safe state
is invented to match a sample image. Seeded data may differ from mock captions.
Phase 5 workflows remain previews. No backend, auth or permission behavior was
replaced with static UI.
